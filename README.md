# An-efficient-heuristic-algorithm-for-software-module-clustering-optimization
This repository contains the replication package for the paper titled "An efficient heuristic algorithm for software module clustering optimization".

To obtain the results, just run the JAR file using the following command:

```java -jar Run.jar
```

After running the JAR file, the results will be stored in the "results" folder. This has been tested on Windows 11 and Ubuntu 22.04 with OpenJDK 24.0.1 and OpenJDK 25.0.2.
